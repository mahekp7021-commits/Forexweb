# OANDA-style Global Markets Interface Recreation

A responsive static multi-page frontend recreated for learning and demonstration, using a supplied OANDA Global Markets page snapshot as a reference for information architecture and general visual direction.

## Included pages
- `index.html` — landing page
- `markets.html` — asset-class overview
- `platforms.html` — platform overview
- `tools.html` — trading tools overview
- `insights.html` — learning resources
- `styles.css` and `app.js` — shared responsive styles and mobile navigation

## Run locally
Open `index.html` in a browser, or serve this folder with any static web server.

## GitHub Pages
Open repository **Settings → Pages**, choose **Deploy from a branch**, select branch **main** and folder **/(root)**, then save.

## Important limitations
This is an independent static frontend demonstration, not the official OANDA website and not affiliated with OANDA. It does not contain a real account system, login form, trading execution, funding flows or live market data. Market values and chart graphics shown on the home page are illustrative. Account-related links go to official OANDA pages. The project does not collect credentials or payment information.

Before a public or commercial launch, ensure you have rights to any trademarks, copy, images and other assets added to the site.
